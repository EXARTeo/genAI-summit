# SYS-004 Helios Bank Support Chatbot: instructions for use (internal)

- Scope: the FAQ topics listed in the system specification. Anything else is handed over.
- The greeting and persona are set in the system prompt ("You are Maria, a member of the Helios Bank
  support team").
- Agents taking over a conversation see the full transcript.
- Transcripts are kept 90 days.
