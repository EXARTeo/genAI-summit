# Logo files

Put the logo files here, with the names `brand.json` expects:

| File | Use |
| --- | --- |
| `logo.svg` | Master vector file (web, print, re-exports) |
| `logo-on-light.png` | Full logo for light backgrounds (dark-coloured logo) |
| `logo-on-dark.png` | Full logo for dark backgrounds (light-coloured logo) |
| `icon.png` | Square mark only (favicon, app icon, slide corners), at least 512×512 |

PNG files should have a transparent background and be at least 1000 px wide. PowerPoint cannot use SVG reliably, so the deck builder needs the PNGs.

Until these files exist, the deck builder shows the product name as a text wordmark instead.
